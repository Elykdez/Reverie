# Reverie

Its all about a sleeping cat on a floating rocky island surrounded by clouds and looping music, a piece of soothing moment to relax by watching.

This could also be considered as my personal unity project template for using gaussian splat assets.

## Getting started

- Install Unity 6 with Android Build Support, SDK, NDK and OpenJDK.
- Install **Git LFS** and run `git lfs install`, then clone and run `git lfs pull` before opening Unity.
- Select **Android** in Unity's Build Profiles, then open `Assets/Scenes/Reverie.unity` and press Play.

Ginger or Oslo is selected randomly at startup. Shake the phone twice in opposing directions, or press **N** on desktop, to switch after loading. Open **Reverie > Splats** for the **Splat Library**: use **Import PLY** to add captures, and **Collection** to configure placement, camera focus, playback and shake sensitivity. Settings are stored in `Assets/Bundles/Resources/Config/SplatCollection.asset`. See [splat setup](Docs/Cat-switching.md).
